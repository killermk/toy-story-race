PROMPT MASTER — RECONSTRUÇÃO COMPLETA DE TOY STORY RACER

MODO CLÁSSICO + MODO MODERNO · PROJETO PRIVADO · IA-FIRST DEVELOPMENT

Você está assumindo um projeto de reconstrução integral de um jogo de corrida clássico, partindo do material original fornecido pelo proprietário do projeto.

O arquivo original deverá estar no workspace ou ser fornecido pelo usuário, normalmente identificado como:

"Disney_Pixar Toy Story Racer.zip.7z"

O objetivo NÃO é criar uma simples imitação.

O objetivo é realizar:

1. engenharia e documentação profunda do jogo original;
2. reconstrução moderna de seus sistemas;
3. preservação de sua identidade;
4. criação de um Modo Clássico, preservando sua experiência;
5. criação de um Modo Moderno, expandindo o projeto sem destruir o original;
6. construção de uma base tecnológica preparada para expansões futuras;
7. desenvolvimento executado exclusivamente por agentes de IA, Claude Code, Codex, plugins, conectores, skills e ferramentas especializadas.

3. PRINCÍPIO DE INTEGRIDADE COMPETITIVA

Esta regra é ABSOLUTA.

RUBBER-BANDING É PROIBIDO.

Nenhum sistema deverá:

- reduzir secretamente a velocidade de quem está vencendo;
- diminuir aceleração do líder;
- diminuir aderência do líder;
- prejudicar o jogador por estar em primeiro;
- aumentar artificialmente a velocidade de quem está atrás;
- teleportar adversários para perto;
- fornecer aceleração oculta para perdedores;
- manipular física para aproximar o pelotão;
- manipular itens para punir quem está ganhando;
- favorecer jogadores simplesmente porque estão atrás;
- alterar resultados para produzir corridas artificialmente apertadas.

Vitória precisa ser conquistada.

Um jogador melhor deve poder abrir vantagem real.

Se alguém dominar:

- pista;
- direção;
- drift;
- atalhos;
- estratégia;
- itens;
- defesa;
- tempo de reação;

ele tem o direito de transformar essa habilidade em vantagem.

- qualidade da racing line;
- tempo de reação;
- frequência de erros;
- agressividade;
- capacidade de defesa;
- uso inteligente de itens;
- estratégia;
- escolhas de rota;
- consistência;
- risco assumido.

Não por:

- velocidade impossível;
- aceleração impossível;
- grip superior escondido;
- teleporte;
- boost invisível;
- física diferente.

No Modo Clássico, preserve a dificuldade original sempre que possível, exceto qualquer mecanismo de rubber-banding que viole esta regra.

Se for identificado rubber-banding no jogo original:

1. documente;
2. prove;
3. preserve essa informação no relatório histórico;
4. NÃO o utilize no gameplay final.
